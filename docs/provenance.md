# Provenance and authorship

This repository consolidates the provided `project1-group2-main.zip` and `project2-group2-main.zip`, originally McMaster COMPENG 4DS4 Group 2 coursework.

Source logic is retained; text line endings may be normalized on upload. `source-manifest.json` records original archive-byte hashes (not normalized GitHub text hashes) and maps included source files to its original archive path and SHA-256 digest. Git history and individual authorship cannot be reconstructed from ZIP snapshots.

Chris Wang is the maintainer of this portfolio consolidation. The original implementation was a team project; specific personal contributions should be documented only after confirming ownership. Vendor notices inside source files remain intact. No new blanket license has been added because rights to all team/vendor material have not been established.

Original reports containing student identifiers, GitHub Classroom badges, IDE metadata and assignment-only `.github/.keep` files are omitted from this portfolio package. This omission does not change the code. Confirm course/team sharing permissions before making the repository public.

The vendor `semihost_hardfault.c` file is excluded from the public repository because its header marks it NXP Confidential and license-controlled. Restore required vendor support only from an authorized SDK installation.
